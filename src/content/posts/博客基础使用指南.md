本文整合本博客（Firefly 主题）的常用操作，每条都写清楚「改哪个文件、改哪一段、怎么改」。所有路径都相对项目根目录 `E:\SoftWare\fireflyblog\Firefly-blog`。

## 环境：本地启动与构建

| 命令 | 作用 |
|---|---|
| `pnpm install` | 安装依赖 |
| `pnpm dev` | 在 `http://localhost:4321` 启动开发服务器 |
| `pnpm build` | 构建到 `./dist/`（含 icon、lqip、pagefind） |
| `pnpm preview` | 预览已构建产物 |
| `pnpm new-post 文件名.md` | 创建新文章 |

注意：构建会先生成图标和低质量占位图，比纯 `astro build` 慢，属正常。

## 头像、名字、社交链接

改 `src/config/profileConfig.ts`。

```ts
avatar: "assets/images/avatar.png",   // 头像
name: "Mical",                         // 名字
bio: "Hello, This is Mical blog.",     // 个人签名
links: [ ... ],                        // 社交链接数组
```

头像支持三种路径：`/assets/xxx`（public 目录，不优化）、`assets/xxx`（src 目录，自动优化，推荐）、`https://...`（远程 URL）。社交链接 `icon` 用图标集代码，预装 `fa7-brands / fa7-regular / fa7-solid / material-symbols / simple-icons`，在 https://icones.js.org 查代码；缺图标集就 `pnpm add @iconify-json/<集名>`。`showName: true` 显示图标+名称，`false` 只显图标。

## 站点 Logo 与标题

Logo 和顶部标题在 `src/config/siteConfig.ts` 的 `navbar` 段：

```ts
navbar: {
  logo: { type: "image", value: "assets/images/my-logo.png", alt: "Logo" },
  title: "Mical Space",
  // ...
}
```

`logo.type` 支持 `icon`（图标库）、`image`（本地图）、`url`（网络图）。`image` 不以 `/` 开头时走 src 目录自动优化。站点全局标题/副标题/描述/关键词、站点 URL 都在这个文件顶部 `siteConfig` 对象里。

## 导航栏菜单与页面开关

导航菜单在 `src/config/navBarConfig.ts`，由 `getDynamicNavBarConfig()` 生成。结构是 `links` 数组，支持多级 `children`：

```ts
links.push({
  name: "链接",
  url: "/links/",
  icon: "material-symbols:link",
  children: [
    { name: "GitHub", url: "https://...", external: true, icon: "fa7-brands:github" },
  ],
});
```

内置项用 `LinkPreset.*`（`Home/Archive/Categories/Tags/Friends/Gallery/Bangumi` 等），定义在 `src/types/config.ts` 的 `LinkPreset` 枚举，对应文案在 `src/constants/link-presets.ts`。部分项是否出现受 `siteConfig.pages.*` 开关控制（见下）。

页面是否可访问（关闭返回 404）在 `src/config/siteConfig.ts` 的 `pages` 段：

```ts
pages: {
  friends: true,    // 友链
  sponsor: false,   // 赞助
  guestbook: false, // 留言板（需配合评论系统）
  bangumi: true,    // 番组计划
  gallery: true,    // 相册
}
```

关掉某块页面后，在 `navBarConfig` 里同步去掉对应的 `LinkPreset` 或条件分支，避免出现指向 404 的导航项。

## 创建文章与 frontmatter

推荐用脚本生成骨架：

```bash
pnpm new-post 我的新文章.md                 # 默认技术记录
pnpm new-post 生活随手.md --group thoughts  # 生活记录
pnpm new-post 技术笔记.md --group tech      # 技术记录（显式）
```

本博客只保留两类 `group`：`tech`（技术记录）和 `thoughts`（生活记录），在 `src/content.config.ts` 用 `z.enum(["thoughts","tech"])` 强制。脚本生成后会在 `src/content/posts/` 下建好文件，frontmatter 如下：

```yaml
---
title: 标题
published: 2026-07-29        # 发布日期
description: '一句话摘要'
image: ''                    # 封面图，可用 ./xxx.webp，或 "api" 启用随机封面
tags: []
category: ''                 # 分类名，留空进「未分类」
group: tech                  # tech | thoughts
draft: false                 # true 时不在生产环境渲染
lang: ''                     # 与站点语言不同时才填，如 en
---
```

可选 frontmatter：`updated`（更新日期）、`pinned: true`（首页置顶）、`comment: false`（关闭此文评论）、`author`、`sourceLink`、`licenseName / licenseUrl`。文章直接写 Markdown 正文，支持 GitHub Flavored Markdown + 提醒块、GitHub 仓库卡片、Expressive Code 代码块、KaTeX 数学公式、Mermaid 流程图。

## 文章加密

在文章 frontmatter 加两个字段即可，无需改任何组件：

```yaml
password: "123456"
passwordHint: "示例密码 123456"
```

机制：构建时用 AES-256-GCM 加密正文，页面源码只有密文（不含明文）。访客输入正确密码后，浏览器用 Web Crypto API 本地解密。同一浏览器会话内密码缓存到 `sessionStorage`，刷新免输；关闭浏览器后失效。可参考示例文章 `src/content/posts/encrypted-demo.md`（密码 123456）。加密实现在 `src/utils/crypto-utils.ts` 和 `src/components/features/EncryptedPost.astro`，一般无需改动。

## 主题色与亮暗模式

在 `src/config/siteConfig.ts` 的 `themeColor`：

```ts
themeColor: {
  hue: 240,            // 色相 0-360，如红0/青200/蓝绿250/粉345
  fixed: false,        // true 时隐藏访客的主题色选择器
  defaultMode: "light", // light | dark | system
}
```

页面整体宽度 `pageWidth`（单位 rem）、卡片边框 `card.border`、卡片是否跟随主题色 `card.followTheme` 也在同一文件。

## 评论区

改 `src/config/commentConfig.ts`。先选 `type`，再填对应配置：

```ts
type: "none",   // none | twikoo | waline | giscus | disqus | artalk
```

每种系统有独立配置块（`twikoo.envId`、`waline.serverURL`、`giscus.repo/repoId/categoryId` 等），字段含义文件内有注释。`none` 表示关闭。单篇文章可用 frontmatter `comment: false` 关评论。

## 友链

改 `src/config/friendsConfig.ts` 的 `friendsConfig` 数组，每条一个对象：

```ts
{ title: "夏夜流萤", imgurl: "https://...", desc: "...", siteurl: "https://...", tags: ["Blog"], weight: 10, enabled: true }
```

`weight` 越大越靠前，`enabled: false` 隐藏某条。友链页底部自定义内容写在 `src/content/spec/friends.md`（由 `friendsPageConfig.showCustomContent` 控制是否显示）。

## 侧边栏布局

改 `src/config/sidebarConfig.ts`。位置 `position: "left" | "right" | "both"`；左右组件各是一个数组，按出现顺序渲染，每项有 `type/enable/position/showOnPostPage`。常见 `type`：`profile`（用户资料）、`announcement`（公告）、`music`（音乐）、`categories`、`tags`、`stats`（统计）、`calendar`、`sidebarToc`（目录）、`advertisement`（广告）。想隐藏某组就把 `enable` 改 `false`，想换顺序就挪数组项。若用单侧栏但想在文章页显示双侧栏，设 `showBothSidebarsOnPostPage: true`。

## 音乐播放器

改 `src/config/musicConfig.ts`，并在 `sidebarConfig.ts` 里把对应 `music` 组件的 `enable` 设为 `true`。配置含播放列表、自动播放、封面等字段。

## 相册

页面开关在 `siteConfig.pages.gallery`。相册数据改 `src/config/galleryConfig.ts`：相册分组、标题、描述、图片列表、封面都在这里。

## 页脚

文本/链接走 `src/config/footerConfig.ts`；需要写自定义 HTML 内容时改 `src/config/FooterConfig.html`，构建时注入页脚。

## 站点统计

在 `siteConfig.ts` 的 `analytics` 段，按需填 `googleAnalyticsId`、`microsoftClarityId`、`umamiAnalytics.*`、`la51Analytics.*`。本地开发时第三方统计脚本 403 属正常（不影响构建）。

## 番组计划

在 `siteConfig.ts` 的 `bangumi` 段填 `userId`，`mode` 选 `static`（构建时取，部署后不更新）或 `dynamic`（客户端实时取，始终最新）。页面开关 `pages.bangumi`。

## 语言（i18n）

站点默认语言在 `siteConfig.ts` 顶部 `const SITE_LANG = "zh_CN"`（可选 `zh_CN/zh_TW/en/ja/ru`）。UI 文案键在 `src/i18n/i18nKey.ts`，各语言翻译在 `src/i18n/languages/`。新增导航项或文案时，给所有语言文件补上对应键，否则类型检查报缺失。

## 快速定位口诀

- 改「人/头像/社交」→ `src/config/profileConfig.ts`
- 改「站点名/Logo/主题色/页面开关/统计/番组」→ `src/config/siteConfig.ts`
- 改「导航菜单」→ `src/config/navBarConfig.ts` + `src/types/config.ts` 的 `LinkPreset`
- 改「文章正文/frontmatter」→ `src/content/posts/*.md`
- 改「文章分类规则」→ `src/content.config.ts`
- 改「评论」→ `src/config/commentConfig.ts`
- 改「友链」→ `src/config/friendsConfig.ts`
- 改「侧边栏」→ `src/config/sidebarConfig.ts`
- 改「音乐」→ `src/config/musicConfig.ts` + 侧边栏开启
- 改「相册」→ `src/config/galleryConfig.ts`
- 改「页脚」→ `src/config/footerConfig.ts` / `FooterConfig.html`
- 改「加密」→ 文章 frontmatter 加 `password`，实现见 `src/utils/crypto-utils.ts`

改完大部分配置 dev 服务器会热更新，但提醒块（Admonitions）主题、部分 i18n 改动需重启 `pnpm dev` 才生效。
