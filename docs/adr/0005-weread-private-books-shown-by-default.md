# ADR 0005：私密阅读的书籍默认公开展示

- **状态**：已接受
- **日期**：2026-09-22

## 背景

微信读书的书架数据带有"私密阅读"标记（`secret`）。该标记在微信读书站内的语义是
"不向微信好友展示"，站主书架中多数书籍处于私密阅读状态；若在博客侧过滤私密书，
微信读书模块将只剩少数几本，失去展示意义。

博客是公开站点，展示哪些书是博客自己的内容决策，与微信读书站内的社交可见性标记
是两个独立的决定。

## 决策

微信读书模块**默认展示全部书籍，不过滤私密阅读标记**。同时在站点配置中保留一个
过滤开关，站主可随时改为只展示公开书或排除指定书籍。

## 后果

- 站主正在读的全部书籍（含私密阅读的）会出现在公开博客上，包括书名、作者、封面与进度。
  这是站主知情的显式选择（2026-09-22 敲定）。
- 私密标记本身不含个人身份信息，展示它不会暴露站主的微信身份。
- 若日后想收紧，改配置即可，无需改代码。
