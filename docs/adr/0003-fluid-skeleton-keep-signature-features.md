# ADR 0003：界面骨架对标 Fluid 风格，特色功能全保留

- **状态**：已接受
- **日期**：2026-09-19

## 背景

站主希望界面对标 mintimate.cn（Hexo + Fluid 主题）的观感：全屏沉浸封面首页、
毛玻璃 sticky 导航、单列横向文章大卡、`日期 / 分类 / #标签` 元信息行、深色模式
质感。同时站主明确界面会**持续迭代**。

站点的既有特色——樱花特效、看板娘（Spine 模型）、壁纸系统、显示设置面板、音乐
播放器——是选择这套主题的原因，对标改版不应以删除它们为代价。

## 决策

采用**骨架级对标**：换版式骨架与视觉语言（hero、导航、卡片、元信息、深色质感），
不逐像素复刻 Fluid。樱花/看板娘/壁纸/设置面板/音乐播放器全部保留，位置随新布局
调整。沉浸首页（见 CONTEXT.md）做成设置项而非固定形态：默认开启，可一键回落到
常规版式。

## 后果

- 改版分阶段进行，先首屏三件套（hero、导航、文章卡），其余页面（归档、相册、
  追番等）维持现状待后续迭代。
- 因为界面会持续变，设置系统的实现必须与面板 UI 解耦（见 ADR-0002），否则每次
  改版都要重写设置逻辑。
- 沉浸首页走注册表，成为新设置体系的第一个使用者与验收用例。
